    altium_api

    Public API for Altium design data access.

    Project Data Loading

    ProjectData

    Complete design data snapshot for a project.

    Exposes only the main design collections: components, nets, and variants.

    components property 

    components: list[Component]

    Get all components in the project.

    Returns:

    Type Description
    list[Component]

    List of Component objects

    nets property 

    nets: list[Net]

    Get all nets in the project.

    Returns:

    Type Description
    list[Net]

    List of Net objects

    variants property 

    variants: list[Variant]

    Get all variants in the project.

    Returns:

    Type Description
    list[Variant]

    List of Variant objects

    Component

    A logical schematic component composed of one or more parts.

    Exposes essential component properties: design_component_id, designator, parameters, name, description, pins, and nets.

    design_component_id property 

    design_component_id: str

    Get the design component identifier.

    Returns:

    Type Description
    str

    Design component ID string

    library_component_id property 

    library_component_id: Optional[str]

    Get the library component identifier.

    Returns:

    Type Description
    Optional[str]

    Library component ID string, or None if not available

    description property 

    description: str

    Get the component description from the Description parameter.

    Returns:

    Type Description
    str

    Component description string

    designator property 

    designator: str

    Get the component designator (logical designator).

    Returns:

    Type Description
    str

    Designator string (e.g., "R1", "U5", "C10")

    name property 

    name: str

    Get the component name.

    Returns:

    Type Description
    str

    Component name string

    nets: list[Net]

    Type Description
    list[Net]

    parameters: list[Parameter]

    Type Description
    list[Parameter]

    type: str

    An electrical pin on a schematic component.

    Exposes essential pin properties: design_pin_id, name, number, and links to the owning component and connected net.

    design_pin_id: str

    Get the design pin identifier of the pin.

    Returns:

    Type Description
    str

    Design pin ID string

    component: Optional[Component]

    Get the component this pin belongs to.

    Returns:

    Type Description
    Optional[Component]

    The owning Component, or None if not resolved.

    description property 

    description: Optional[str]

    Get the pin description.

    Returns:

    Type Description
    Optional[str]

    Pin description string, or None if not provided.

    electrical_type: Optional[str]

    Get the pin electrical type.

    Returns:

    Type Description
    Optional[str]

    functions: list[str]

    Get the pin functions.

    Returns:

    Type Description

    Type Description

    Optional[Net]

    number: str

    Type Description

    Optional[float]
